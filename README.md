# 🐾 Registros Comida Baloo

App de registro de alimentación y medicación para Baloo.

## Registro por toma

| Categoría | Unidad | Incrementos |
|-----------|--------|-------------|
| Pienso | gramos | +10, +20, +30, +40, +50, +60 |
| Puré | cucharas | +1, +2, +3, +4, +5, +6 |
| Caballo | puñados | +1, +2, +3, +4, +5, +6 |
| Micofenolato | pastilla | 1 (toggle) |
| Corticoides | dosis | +¼, +½, +¾, +1 (acumulativo) |

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue en Vercel

1. Sube el repositorio a GitHub
2. Importa el proyecto en [vercel.com](https://vercel.com)
3. Framework preset: **Vite**
4. Deploy automático
